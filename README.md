# 🏅 _Olympic Games Data Analysis: 120 Years of Athletic Excellence_
## 📌 Overview

This project focuses on analyzing Olympic Games athlete data using SQL.
The analysis includes exploring athlete demographics, performance trends, and medal distributions.

We use SQL queries to answer real-world business-style questions, showcasing data manipulation, aggregation, and filtering.

## 📂 Dataset

The dataset contains information about athletes, events, and results from various Olympic Games.

Key Columns:

Name – Athlete’s full name

Sex – Gender of the athlete

Age – Age of athlete during the event

Height – Height in cm

Weight – Weight in kg

Team – Represented country/team

Sport – Type of sport

Event – Specific event participated

Medal – Medal won (Gold, Silver, Bronze, NA)

## Key Statistics

**Time Period:** 1896 (Athens) to 2016 (Rio)

**Total Athletes:** ~135,000 unique individuals

**Countries:** 230+ nations and territories

**Sports:** 60+ different sports

**Events:** 700+ unique events

## 🎯 Objectives

Learn SQL querying using real-world sports data

Explore patterns in athlete participation and performance

Answer business-style case study questions

## 📊 Case Study Questions

1.What is the average age of athletes who won a gold medal?

2.Which country has won the most medals in the history of the Olympics?

3.Find the top 5 athletes with the most medals.

4.Compare the average height & weight of male and female athletes.

5.Which sports have the highest number of unique medal winners?

6.What is the average weight difference between male and female athletes in the same event?

7.Which country has the highest ratio of gold medals to total medals?

## 🛠️ Tech Stack

SQL (MySQL / PostgreSQL) – Data querying & analysis

Python (Optional) – For data import/export

Jupyter Notebook / VS Code – Running queries & documenting
